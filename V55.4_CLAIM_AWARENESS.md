# V55.4 — Claim-aware RSS selection

AUTO GATHER must be conservative around other players.

Rules:
- If an RSS tile is visibly occupied by another player, exclude it.
- If a player is visibly marching toward/approaching the tile, exclude it.
- If ownership/approach state is uncertain, exclude it and rescan later.
- Only a clearly free tile with sufficient claim-state confidence can reach the existing AUTO GATHER gate.

This layer is intentionally a skip/filter, not a mechanism for taking a tile from another player. It sits before target authorization and preserves the existing Grid LOCK + Tile Panel verification requirements.

# V55.2 — Grid learning + simulation

## Design decision

Do not run a heavyweight neural network on every screenshot. The game grid is
structured and approximately isometric, so the fast path uses an **online
learned affine lattice model** from observed `(game X, game Y) -> (screen X,
screen Y)` pairs.

The learner is ML-friendly: observations can later be persisted as training
samples, while the runtime remains lightweight.

## Lock criteria

The model requires at least 10 observations and median projection residual <=
14 px before AUTO GATHER can use it. Until then the app may scan/display
candidates but must not issue a troop-action tap.

## Simulation requirement

`simulation/grid_simulation.py` generates a synthetic isometric map, adds small
screen noise, fits the same model, and repeats the test after a viewport
translation. It asserts the lock threshold and prints `SIMULATION PASS`.

## Next integration

Feed authoritative X/Y OCR plus validated RSS badge centers into
`GridLearningEngine`. Use its residual as the gating signal for target taps.
Keep `TilePanelVerifier` as the final truth check before Gather.

# V55.1 — Verified Viewport State Machine

Baseline: `v54-compact-overlay`

## Goals
- Preserve the working V54 Android implementation.
- Treat authoritative game X/Y as the only proof that a coverage swipe changed the map.
- Never advance the sweep route merely because a gesture was dispatched.
- Require calibrated tile-grid state before autonomous Gather.
- Keep tile-panel verification as the final Gather gate.

## State flow
`CAPTURE -> READ_VIEWPORT -> CLASSIFY_VIEWPORT -> CALIBRATE_GRID -> VALIDATE_TARGET -> ACT`

Coverage movement:
`READY -> SWIPE_SENT -> WAIT_FOR_NEW_VIEWPORT -> MOVED`

If repeated authoritative observations remain identical, enter recovery instead of issuing unlimited swipes.

## Safety invariants
1. No fabricated game coordinates.
2. No route advancement without confirmed viewport change.
3. No autonomous Gather while grid calibration is unlocked.
4. No Gather click without a verified tile panel and visible Gather control.
5. A failed gesture does not advance coverage state.

## Test checkpoint
Install/build only after the Android branch compiles successfully. Validate first with scanning only; enable Auto Gather only after the viewport and grid states behave correctly on-device.
